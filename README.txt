# บันทึกงานคนงาน — ต้นแบบใช้งานได้

## มีอะไรบ้าง
- เพิ่ม/แก้ไข/ลบรายชื่อคนงาน
- กำหนดค่าแรงรายวัน รายสัปดาห์ หรือรายเดือน
- บันทึกเต็มวัน ครึ่งวัน ไม่มา และ OT
- บันทึกเงินเบิกล่วงหน้า
- รายงานค่าแรงตามช่วงวันที่
- ส่งออกรายงาน CSV (เปิดด้วย Excel ได้)
- พิมพ์รายงานหรือเลือก Save as PDF
- สำรอง/นำเข้าข้อมูล JSON
- โครงสร้าง PWA สำหรับเพิ่มลงหน้าจอ iPhone/Android

## วิธีทดลองเร็วที่สุด
เปิด `index.html` ในเบราว์เซอร์สมัยใหม่ได้เพื่อทดลองฟังก์ชันส่วนใหญ่ ข้อมูลจะเก็บใน localStorage ของเบราว์เซอร์นั้น

## วิธีเปิดเป็นแอปบนมือถือ
การติดตั้ง PWA ต้องโฮสต์ไฟล์บน HTTPS (หรือ localhost) ก่อน ไม่สามารถติดตั้ง PWA โดยเปิดไฟล์ในเครื่องโดยตรงได้
1. อัปโหลด `index.html`, `manifest.json`, `sw.js` ไปยังโฮสต์ static HTTPS เช่น GitHub Pages หรือ Netlify
2. เปิด URL ที่ได้ใน Safari บน iPhone
3. กด Share > Add to Home Screen > Add
4. Android: เปิด URL ใน Chrome แล้วเลือก Install app หรือ Add to Home screen

## ข้อจำกัดสำคัญของต้นแบบ
- ข้อมูลเก็บในเครื่องและเบราว์เซอร์ปัจจุบันเท่านั้น ยังไม่ซิงก์หลายเครื่อง
- ไม่มีบัญชีผู้ใช้หรือระบบคลาวด์
- รายงาน CSV เปิดด้วย Excel ได้ แต่ยังไม่ใช่ไฟล์ .xlsx โดยตรง
- PDF ใช้เมนู Print ของเบราว์เซอร์
- การคิดรายเดือนเป็นค่าแรงรายเดือน ÷ 30 × จำนวนวันทำงานที่บันทึก และ OT = ชั่วโมง × อัตรา OT ที่กรอกในแต่ละรายการ ควรปรับกติกาตามข้อตกลงการจ้างจริงก่อนใช้จ่ายเงินจริง
- ต้องสำรองข้อมูล JSON เป็นประจำ

## แนะนำก่อนใช้กับเงินจริง
ทดลองกรอกข้อมูลสมมติ ตรวจยอดค่าแรงและเงินเบิกทุกกรณี แล้วให้ผู้ดูแลตรวจสอบสูตรค่าแรง/OT/การหักเงินให้ตรงกับวิธีจ่ายของกิจการ
